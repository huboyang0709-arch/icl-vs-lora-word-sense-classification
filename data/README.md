# Data

The dataset is not redistributed here. It is downloaded automatically by `load_data()` in `lab1_shared.py`, or
manually:

```
wget http://www.linguist.univ-paris-diderot.fr/~mcandito/divers/super_wiktionary_labeled_data_simplified.noex.25labels.tsv.gz
```

Place the file in this folder to run `notebooks/04_error_analysis.ipynb`.
